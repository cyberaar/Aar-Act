# Examples

Templates, case studies and sample reports that go with the guides in
`practices/`.

An example earns its place by being concrete: a real configuration, a real
report, a real incident written up so that someone can follow what happened and
what was changed in response. West African public sector cases are the ones this
project knows best and they are welcome here, but nothing about the folder is
limited to them.

Nothing here yet beyond this note. If you have a template you already use, that
is the most useful thing you can contribute: see
[CONTRIBUTING.md](../CONTRIBUTING.md).
