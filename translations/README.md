## Contribuer

Pour ajouter une traduction :

1. Créer un fichier dans ce dossier avec le même numéro de préfixe que le guide
   source, afin que la paire reste évidente.
2. Garder le contenu technique identique au guide source. Une traduction n'est
   pas une réécriture.
3. Adapter les exemples au contexte francophone (administrations, secteur
   public, infrastructures critiques) là où cela rend le guide plus clair.
4. Ouvrir une pull request en référençant le guide source.

Le français s'écrit avec tous ses accents : leur absence est une contrainte de
clavier, pas un style. Pas de tirets cadratins non plus, dans aucune des deux
langues.
